# Kredit aset Racik Sumatera

## Koleksi asli tim

50 gambar di `gambar/` diimpor dari ZIP yang disediakan tim. File asli tidak diubah. `../data/assets.json` memetakan setiap file asli ke versi WebP di `images/`, termasuk ukuran gambar.

**Status lisensi: belum dikonfirmasi.** ZIP tidak memuat kredit fotografer atau lisensi individual. Penyertaan aset bukan bukti hak redistribusi. Tim perlu mendata pencipta, sumber asli, izin, dan lisensi sebelum publikasi. Foto diberi label ilustrasi jika tidak mendokumentasikan spesies, praktik, atau lokasi yang sedang dibahas.
