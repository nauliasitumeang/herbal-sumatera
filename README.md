# Herbal Tradisional Sumatera

Website edukasi tentang obat tradisional dari berbagai suku di Pulau Sumatera. Proyek ini dibuat untuk tugas **Cultural Awareness** (Kelompok 4).

🔗 **Website:** [link Vercel menyusul]

## Tentang Proyek

Banyak ramuan tradisional di Indonesia diwariskan turun-temurun dan menjadi bagian dari identitas budaya. Proyek ini mendokumentasikan ramuan dari beberapa suku di Sumatera dengan dua tujuan:

1. **Melestarikan dan mengenalkan** warisan budaya pengobatan tradisional.
2. **Mengedukasi** bahwa "alami" tidak selalu berarti "bebas risiko", dan pentingnya berkonsultasi dengan tenaga medis, terutama bagi yang sedang menjalani pengobatan medis.

Proyek ini sejalan dengan **SDG 3 (Good Health and Well-Being)** dan **SDG 4 (Quality Education)**.

## Disclaimer

Informasi di website ini bersifat **edukasi budaya**, bukan saran medis. Penggunaan ramuan tradisional dalam konteks ini adalah praktik **yang secara tradisional dilakukan** dan bukan klaim penyembuhan. Konsultasikan dengan dokter, apoteker, atau perawat sebelum mengonsumsi ramuan herbal, terutama jika sedang hamil, menyusui, memiliki penyakit kronis, atau sedang mengonsumsi obat.
